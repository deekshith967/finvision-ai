FinVision AI — Personal Finance Management Platform

A full-stack AI-powered personal finance tracker built with
Next.js, Tailwind CSS, Prisma, Supabase, Shadcn UI, and Gemini AI.

This project helps users manage expenses, analyze spending patterns, and use AI to extract insights from receipts.

 Features

 Add & manage financial transactions

 AI-powered receipt scanning using Gemini API

 Personal finance dashboard with analytics

 Secure authentication (Clerk)

 Email notifications for account activities

 Clean & responsive UI using Tailwind + Shadcn

 Supabase + Prisma database with schema models

 Server Actions for fast backend operations

 Tech Stack

Frontend: Next.js, Tailwind CSS, Shadcn
Backend: Next.js Server Actions, Inngest
Database: Prisma ORM + Supabase
AI: Google Gemini API
Auth: Clerk
Email: Resend
Security: ArcJet
Languages: TypeScript, JavaScript

 Folder Structure
